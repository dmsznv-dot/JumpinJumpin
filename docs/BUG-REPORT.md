## Производительность

Замер: Mac, 120 Гц, DPR 2, режим «Мега-Хаос», Гекса-арена, одна и та же секунда раунда.

| | До | После |
|---|---|---|
| Draw calls на кадр, Гекса-арена | 467 | 70 |
| Draw calls на кадр, «Большие вентиляторы» | 325 | 277 |
| `game.js` | 5 237 строк | 4 651 строка |
| Архив для Яндекс Игр | 798 КБ, 44 записи | 342 КБ, 30 файлов |

Что сделано:
- Целые соты рисуются `InstancedMesh` (3 на ярус); сота, на которую наступили / падающая / восстанавливающаяся берёт меш из пула — картинка прежняя.
- HUD пишет в DOM только изменившиеся значения.
- Общие геометрии и материалы бонусов (раньше на каждый спавн создавались новые и не освобождались).
- `THREE.Cache` — `colormap.png` грузится один раз, а не три.
- Удалён мёртвый код старой «фасолинки» (`createBean3DMesh`, `getBeanPatternTexture` и т. п., ~660 строк).

Не сделано (кандидаты на следующий заход, по убыванию пользы):
- Пул/инстансинг частиц (`spawnParticles3D` создаёт меш и материал на каждую частицу).
- Числовые ключи сот вместо строк `` `${q},${r}` `` и вынос массивов направлений из горячих циклов ИИ ботов.
- Понижение детализации глаз/капсул куба (`SphereGeometry(1,20,14)` на точку, `CapsuleGeometry(…,6,16)`).
- Объединение колонн стадиона через `mergeGeometries` (~−90 draw calls).
- Адаптивный `pixelRatio` на слабых телефонах.
- `slimeGlowLight` почти не даёт вклада, но считается во всех PBR-материалах — проверить визуально и убрать.

## Сборка

`build-yandex-zip.sh` теперь: тесты → граф рантайм-файлов от `index.html` (`tools/runtime-files.mjs`) →
проверка, что всё закоммичено → `git archive HEAD` → `?v=<коммит>` для модулей и `modulepreload`
(`tools/stamp-version.mjs`) → zip → бюджет 1 МБ.

Не сделано: SDK Яндекс Игр (`YaGames.init()` + `LoadingAPI.ready()`) не подключён — без него модерацию,
скорее всего, не пройти; GitHub Pages отдаёт файлы без версии (возможна смесь старых и новых модулей до 10 минут после деплоя).

`assets/models/sketch-runner.glb` (1,9 МБ) и `cube-runner.glb` — только результат экспорта из `characters/tools/`, игра их не грузит.
Если оставлять в репозитории: `npx @gltf-transform/cli` (prune → dedup → weld → quantize) уменьшает их вдвое без новых декодеров.
