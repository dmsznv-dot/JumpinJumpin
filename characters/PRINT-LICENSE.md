# Print assets

Author: Steve Schoger. Collection: Hero Patterns, https://heropatterns.com/
Source: https://github.com/sschoger/hero-patterns/blob/master/js/app.js
License: Creative Commons Attribution 4.0 International, https://creativecommons.org/licenses/by/4.0/

Active Hero Patterns artwork: Random Shapes, Diagonal Stripes, Polka Dots, Zig Zag, Leaf, Circuit Board, Hexagons.

Five Point Stars, Fluffy Clouds, Hypnotic Rings, Candy Waves and Harlequin Diamonds are original game-authored SVG motifs dedicated under CC0 1.0 (https://creativecommons.org/publicdomain/zero/1.0/). They replace misleading aliases while keeping saved pattern IDs.

Changes: rasterized into shared 1024px single-channel masks, recolored with player palettes, repeated and projected onto character surfaces. Credits also appear in game settings and the character preview. No endorsement implied.

All source SVGs are embedded in hero-patterns.mjs. Runtime needs no third-party network requests.
