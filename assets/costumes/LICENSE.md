# Costume models

The `.glb` files in this folder are adapted from **NVIDIA SimReady Assets**
(https://huggingface.co/datasets/nvidia/simready-assets), © NVIDIA Corporation,
licensed under **CC BY 4.0** (https://creativecommons.org/licenses/by/4.0/).

Changes: geometry decimated (~1000 triangles), rescaled into the cube character's suit box,
face window cut out, PBR textures replaced by a 4-tone vertex-colour palette.
Built by `tools/costumes/build.py`; source asset per costume is listed in `characters/costume-manifest.mjs`.
